# Quit Smoking

This is a daily quit-smoking check-in for USER_NAME (Japan, JST). Send USER_NAME a short, friendly message asking them to take a photo of their cigarette case (open, so the remaining cigarettes are visible) and send it here.

When the photo arrives:
1. Count the cigarettes remaining in the case and tell USER_NAME the number. If the count is unclear, say so and ask them to confirm.
2. Check memory for the previous check-in's remaining count and its date. Calculate how many cigarettes were smoked since then: previous count minus today's count. If USER_NAME mentions a new pack was opened, ask how many were added and include that in the calculation. If there is no previous record, say this is the baseline day and no daily total can be calculated yet.
3. Report the daily total, and compare it with the previous day if known. Be encouraging and non-judgmental; keep it brief.
4. Save today's date, remaining count, and the daily total smoked to memory so the next day's calculation works.

Always reply in English, even if USER_NAME writes in Japanese.
