# Daily Routine

## Morning
- [ ] 1. Make the bed
- [ ] 2. Prepare a towel
- [ ] 3. Write today's task checklist
  - [ ] Rank the tasks by importance × urgency (high/high → high/low → low/high → low/low)
  - [ ] Book a 30-minute review slot before each deadline
- [ ] 4. Clock in on freee

## Workday
- [ ] Before each meeting
  - [ ] 15 minutes before: go to the toilet
  - [ ] 10 minutes before: join the meeting
- [ ] Reply to internal and external messages within 2 hours
- [ ] When a mistake or feedback comes up, write its cause and the fix in the notes
- [ ] Clock out on freee

## Evening
- [ ] 1. Drink only water or protein (skip the convenience store)
- [ ] 2. Cook
- [ ] 3. Work out
- [ ] 4. Bath
  - [ ] Take off the AirPods and clothes here, and nowhere else
  - [ ] Face: wash, moisturize, sheet mask
  - [ ] Body: moisturize
- [ ] 5. Laundry
- [ ] 6. KPT reflection, and pick tomorrow's experiment
- [ ] 7. Charge every device
  - [ ] AirPods
  - [ ] Private smartphone
  - [ ] Office smartphone
- [ ] 8. Set the alarm
- [ ] 9. In bed by 24:00
